# Dedicated Challenges board

Scope: user-requested Challenges menu, difficulty tiers, reward presentation,
clear winning rules and faster program stopping. Visual reference: DESIGN.md,
Quest and Help menus. Existing sprites plus the user's icon_challenges.png.

- Direction PASS: slate-framed light panels, Quicksand, green primary actions,
  Bot Teacher and game artwork retained. No new theme or generated imagery.
- Purpose PASS: collapsed entries reduce reading; tier filtering finds an
  appropriate task; completion count uses rewards actually earned on this farm.
  Illustrated reward items separate coins, EXP and seeds with padding and gaps.
- Interaction PASS on the tested path: menu icon opens next to Quests, beginner
  expansion exposes requirements, Expert filter leaves the master patrol,
  expanded expert rules include the return trip, and Stop & edit preserves code.
- Feedback PASS: browser test stopped a repeating movement program in about five
  seconds; result showed the failed requirements. A corrected beginner solution
  scored 3/3, claimed 90 coins, 80 EXP and eight seeds, and updated the board to
  1/6 rewards earned. Existing reward motion and confetti remain.
- Verification PASS: 199 tests cover all task solutions, return-trip failure,
  runaway limits and stopped-first-run provenance. Production build passes.

Browser screenshots checked at 1280x720. The panel and reward layout wrap and
scroll rather than imposing a fixed content width. This scoped check is not a
full accessibility audit of the existing game. Existing build accessibility and
bundle-size warnings remain.
