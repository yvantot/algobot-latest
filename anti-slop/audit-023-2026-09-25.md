# Challenge pause and reward presentation

The pest task's expiring tomato opened a main-game freshness tip. Game.svelte hides that popup's container during challenges, but its effect still set the engine speed to zero. The previous component tests stubbed tips, and the browser fixture omitted the popup, so they missed this interaction.

Freshness now accepts an explicit tip setting. Isolated farm crops disable it, and corn synergy also suppresses its main-game tip on isolated farms. Their visual effects remain. Normal-farm tips remain enabled. The browser fixture now includes the real popup behind the same hidden-container behavior.

The shared difficulty badge uses the requested green, yellow, red and black tier palette with visible tier names and contrasting text. It appears in the menu and challenge header. Existing menu layout and animations remain. Rewards use the inventory coin at 40px and a 40px green XP badge rasterized from its checked-in SVG. The renderer uses System.Drawing and requires no added dependencies. The small gameplay EXP particle is unchanged.

Verification: 221 tests pass; production build passes with the existing bundle-size warning. Browser reproduction showed the hidden popup freezing the farm before the fix. After the fix, Before the pests completed both rows at 6/6, displayed the emptied soil after pest attacks, and granted the fixture reward of 650 coins and 500 EXP. Menu tier colors and reward artwork were visually checked. Fixture runs do not write participant data. No separate mobile-device walkthrough was performed.
