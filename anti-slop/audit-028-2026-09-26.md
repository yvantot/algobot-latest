# Version 1.3 isolated mission practice

Applied the user's existing after-mode review preference. Practice uses the established slate borders, light panels, green action buttons and Quicksand type. Bot Teacher and the live farm remain the focus; no new artwork or interface theme was introduced. Panels enter and leave with motion; the program panel can resize.

The farm window is transparent to show the actual KAPLAY entities. Each lesson starts with a small relevant toolbox. Help is requested explicitly, matches the current editor and disappears when progress advances. The main mission card links to practice rather than showing instructions for the wrong farm. Replay text says rewards were already earned.

The full Events-to-Upgrades browser sequence exposed an out-of-range chapter render error. A valid fallback chapter is now selected while the new lesson resets. Spoilage appears only in the short introduction. The initial main-editor spotlight no longer intercepts menu clicks; lessons live in their own farm.

Automated checks run all thirteen lesson solutions with real entity components, reject an unrolled loop solution, bound infinite loops, and verify no main-farm harvest rewards. The existing reward claim guard prevents repeat mission rewards. Guided practice is recorded separately from normal gameplay and scored Challenges.

No additional visual redesign proposed.
