# LSTM-only research UI review

The existing menu style and motion are retained. Scope is removing obsolete DQN information, not redesigning the research panels.

- Removed Q-value display and DQN mode labels because the runtime no longer uses that policy (R-26, R-38).
- Dashboard identifies the LSTM estimate and rule-selected difficulty. Historical replay export remains available for research continuity.
- No assets or visual treatments added. Model experiments preserve actual outcomes, including failure to beat the baseline; simulated observations remain identifiable.
- Runtime behavior and model artifacts are covered by automated tests and the production build. This change did not include a new browser visual audit.
