# Documentation menu implementation review

Scope: Documentation and its editor/preview interactions, using DESIGN.md and
the existing Quest and Help & Game Guide menus. ENERGY 2 / RHYTHM 2 / MOTION 2.

- Direction: light gray panels, slate outlines, Bot Teacher, green actions and
  framed code examples retain the game's existing menu vocabulary. No new art.
- Purpose: short entries and expandable details replace the wall of text.
  Command-name search and category/availability filters narrow the catalog;
  mission recommendations and recent entries support returning to a task.
- Liveliness: panel/detail transitions and optional real gameplay previews give
  actions context. Reduced-motion preferences disable interface transitions.
- Interaction: supported examples render actual Blockly blocks and can be
  appended to either editor. Insertion preserves existing work and supports
  undo. Locked commands and locked dependencies explain why insertion is blocked.
- Layout: the reference is resizable. Wide screens show the editor beside it;
  narrower screens switch between reference and editor while retaining state.
  Inventory remains outside the reference panel. Opening another menu closes it.
- Verification: 144 automated tests passed; all 40 preserved research artifacts
  verified unchanged. Production build passed. Browser checks covered search,
  lock requirements, copy feedback, Blockly/text insertion and undo, retained
  reference state, and movement/watering previews with farm-state restoration.
  Desktop layouts inspected at 1280 and 1600 pixels wide.
- Limits: entries without a validated standalone example remain readable and
  copyable; insertion is disabled with an explanation. Preview coverage is
  movement, planting, watering, harvesting and extinguishing. Existing build
  warnings remain; Svelte also flags the intentionally focusable code region
  used for keyboard scrolling. This review does not certify the whole game's
  accessibility or phone layout.
