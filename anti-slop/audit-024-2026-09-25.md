# Shared challenge text editor

Reused Bot Command's CodeMirror setup through a shared factory rather than adding a second editor configuration. Its dark theme, yellow selection, command hover help and Courier Prime code font follow the existing component. Challenge panel layout, transitions and vertical resizing remain. Blockly and text remain separate modes; the system does not pretend arbitrary JavaScript can be converted back into blocks.

Challenge completion lists contain allowed commands, bot, row/column queries and syntax. Shop/inventory and unavailable commands are omitted. Available task commands do not show quest-lock labels. The main farm retains its full command lists and runner controls.

Verification: 225 automated tests pass, including completion restrictions and partially typed names. Browser checks confirmed completion choices, text persistence across mode switches, independent team-bot undo/redo, and Pass it on scoring 6/6 across both rows. The actual challenge runner reads the editor values; the two editors do not bind to main-farm robot state. Production build passes with existing warnings. No separate mobile-device test was performed.
