# Version 1.2 mission help and challenge modes

Retained the existing menu layout, colors and typography. Alert sprites render at their native 22 by 36 dimensions without rotation, filtering or animation. Menu alerts clear on opening; the optional-lesson Help alert follows lesson completion.

Mission help uses actual read-only Blockly blocks with connection movement and reduced-motion support, or readable code when Text mode is selected. All 22 mission recipes and their hint levels are checked against the real Blockly generators. Requested hints, including repeated clicks, retain help telemetry.

Recommended and Freestyle are labeled radio choices with a short explanation. The challenge header repeats the active mode. Rewards remain visible in the menu and result panel, without the duplicate Commands & Rewards section inside the editor. Existing challenge transitions and editor resizing remain.

Browser checks used isolated fixtures without saving participant data: switching block/code hints, animated nesting, opening Freestyle with its expanded toolbox, and running a jumping harvest program. Automated tests cover command restrictions, all scenario solutions in Freestyle, practice entry without a fresh window, and mode exclusion from training targets.

No further visual redesign proposed in the after-mode review.
