# Version 1.1 beginner flow

Applied the user's observed usability issues within the existing slate, green, Quicksand design. No new artwork: Help uses the supplied icon_alert.png. Requested hints show actual read-only Blockly blocks moving into a repeat/if body, not screenshots. Reduced-motion settings skip the movement. The hint button uses a contrasting border and a limited three-cycle pulse when assistance is offered.

The opening contains six chapters. Optional Events and Upgrades lessons keep the existing real entities, curtains, program-panel transitions and resizing. Help explains their one-time per-farm rewards; skipping or closing early grants nothing. Replay is available without repeated rewards. The alert remains until both optional rewards have been collected.

Required practice ends after the first harvest. Completed practice code is cleared only after the active run finishes; free-play mission programs are not automatically cleared. Plain-English labels retain block IDs, inputs and generated code. Tips have one short action or fact each.

Browser verification used an isolated fixture without saved participant data: movement command labels, completing Move down and arriving at Say hello with an empty workspace, animated repeat/if nesting, optional Help choices/reward text, and opening Events. Automated real-entity tests complete the short introduction and each optional lesson separately, including purchases and farm cleanup. No student data was changed.

No additional design changes proposed in the after-mode review. Collection and scoring remain governed by existing phase/exposure rules; version 1.1 changes the learning sequence and should remain identifiable when comparing study sessions.
