# Challenge availability after interrupted gameplay

User-reported functional defect: the invitation and Challenges navigation vanished when a sampling gap invalidated the recent gameplay window. The latest supplied session became ready at 04:45:44 UTC, lost readiness following a 10-second sampling gap at 04:46:09 UTC, and ended before the last gap had left the window. The export alone cannot identify which UI action caused each gap.

Fixed within the requested scope: keep navigation, menu and pending invitation available after the first unlock in the current game session. Entry remains disabled during an invalid window, with a brief explanation. Once ready, entry enables automatically. Existing modal suppression, animations, theme and typography remain. No new assets or layout redesign.

After-mode review: no additional design changes proposed. The waiting state has visible text and native disabled controls; the invitation remains dismissible. Tests cover initial locking, unlocking, a hidden tab, gap recovery, modal interruption and tutorial reset. All 229 tests and the production build pass (existing build warnings remain). No browser visual check was performed for this patch.
