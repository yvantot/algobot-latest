# Blockly media

Files in `media/` are copied unchanged from the installed `blockly` npm package, version 12.4.1. They are served locally so the Challenge Farm editor does not depend on a media CDN during data collection.

Blockly is copyright Google LLC and the Blockly contributors, licensed under Apache License 2.0. Source and license: https://github.com/google/blockly/tree/blockly-v12.4.1

When upgrading Blockly, refresh these media files from the same package version.
